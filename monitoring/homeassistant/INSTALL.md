# Установка VPN Monitoring Dashboard в Home Assistant (iPhone / веб-интерфейс)
Дата: 2026-11-04

## Перед началом
Источник полной панели: `monitoring/homeassistant/keenetic_vpn_dashboard.yaml` в ветке `feature/vpn-monitoring-home-assistant-20261104`. Это **конфигурация всего dashboard** с корневым ключом `views:`, а не YAML отдельной карточки. Использует только встроенные карты HA.

В этой сессии управление Home Assistant через MCP недоступно. Файл создан в GitHub, **не установлен в HA**; никаких токенов HA в чат/репозиторий не передавать.

## Импорт через интерфейс HA
1. Откройте Home Assistant в локальной сети (ранее `http://192.168.0.169:8123`) в браузере.
2. `Настройки → Панели управления (Dashboards) → Добавить панель`. Название: `VPN Monitoring`, URL: `vpn-monitoring`. При создании выбрать пустую панель, если UI предлагает.
3. Откройте новую панель → меню `⋮` → `Изменить панель` → `⋮` → `Редактор исходной конфигурации (Raw configuration editor)`.
4. Вставьте **всё** содержимое `keenetic_vpn_dashboard.yaml` вместо существующей конфигурации панели и сохраните. В некоторых версиях HA сначала нужно `Взять управление` (Take control).
5. Проверьте, что открывается view `VPN и OpenAI` с таблицей 7 узлов, статусами OpenAI, VLESS, 24h/7d историей и длительностью тестов.
6. Проверьте `Настройки → Устройства и службы → Сущности`, фильтр MQTT / Keenetic VPN: все ожидаемые entity_id доступны. При переименовании OpenAI датчиков шаблон поиска по friendly_name покажет `нет датчика`; нужно адаптировать сопоставление по реальным идентификаторам.
7. Сопоставьте последний `checked_at` с текущим временем; `unknown` и `unavailable` не интерпретировать как успешную проверку.

## Пояснения к показаниям
- VLESS `ok` = HTTP egress изолированного маршрута; не равно OpenAI `reachable`.
- OpenAI сенсоры по 3 на узел: reachability, checked_at, test_duration_ms; MQTT `expire_after=1800`.
- Полная длительность HTTP-пробы ≠ RTT.
- Интерфейсные счётчики `apclii0`, `br0`, `br1` не являются per-outbound VPN bytes; их нельзя суммировать для «общего VPN трафика».
- `vpn06` и `vpn07` по последним сохранённым измерениям возвращали OpenAI `network_error`. Панель должна показывать новые данные, а не зашитое статическое состояние.

## Границы и откат
- Импорт панели меняет только конфигурацию выбранного dashboard, без Xray, cron, маршрутов или MQTT.
- Перед вставкой скопируйте старый Raw YAML, если панель не пустая. При проблеме верните старый YAML или удалите созданную панель.
- Не устанавливайте дополнительные HACS/custom cards ради этой версии.
