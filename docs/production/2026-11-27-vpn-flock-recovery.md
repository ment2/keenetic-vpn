## Критерии окончательной приёмки
Два последовательных штатных завершённых цикла после CRON_FIXED, журнал с новыми SUCCESS/UNCHANGED (SKIP/ROLLBACK отдельно расследовать), отсутствие унаследованного FD рабочего Xray после фактического применения, неизменный inode, сохранённый watchdog, HTTP204/401. Отсутствие нового пула при UNCHANGED штатно, не форсировать рестарт. HTTP401 означает достижимость API без ключа, не авторизованную работу ChatGPT. Не доказана доступность всех VLESS, UDP/TPROXY или отсутствие перерыва соединений. В 16:00:08 два 15-минутных цикла ещё не могли завершиться. Задание 3e3eabe5-87e4-4495-b4b1-e2242b11c589 завершено, не дублировать. Новая read-only проверка после завершения следующих штатных циклов.

## Rollback
При выявленном сбое прежде всего остановить только расписание сборщика после свежей проверки и нормализованного сравнения с fixed; использовать сохранённую paused, не восстанавливать неисправную строку автоматически. Не удалять lock-файл, не прерывать выполняющийся apply, не менять конфигурацию/маршруты вслепую. Возврат original только по отдельному согласованию. Никаких дополнительных мутаций в этой проверке.
